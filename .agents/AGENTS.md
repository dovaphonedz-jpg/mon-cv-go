# Règles de l'Assistant

- Toujours tester les modifications avant de livrer le résultat à l'utilisateur (par exemple : vérifier que le serveur de développement tourne sans erreur, utiliser le subagent navigateur si besoin, ou s'assurer que le build passe).
- **Règle Multilingue Obligatoire** : Tout nouveau contenu, page d'atterrissage, fonctionnalité ou composant ajouté au site DOIT impérativement être intégralement traduit et configuré dans les 4 langues du site (Français `fr`, Anglais `en`, Allemand `de`, Arabe `ar`) dès sa création.
- **Règle Backlinks Multilingues** : Toute stratégie de netlinking / backlinks pour le site doit être rédigée et optimisée en 4 langues (FR, EN, DE, AR) pour cibler l'acquisition de trafic international.
